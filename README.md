# ⚡ ARES FORGE - High-Performance Gym & Fitness Landing Page

A high-energy, premium landing page designed for modern fitness centers, CrossFit boxes, and elite personal trainers. Built with a dark, immersive aesthetic, neon green accents, and a focus on high conversion rates through clear pricing tiers and bold typography.

## ✨ Key Features & UI/UX Highlights

- **Dynamic Dark Theme:** Deep carbon/midnight gradients (`radial-gradient`) combined with vibrant neon accents (`#c4ff00`) to create a 3D, elevated depth effect.
- **Fluid Typography:** Utilizes CSS `clamp()` for responsive, perfectly scaled headings (`Oswald`) and readable body text (`Roboto`) across all screen sizes.
- **Advanced Accessibility (a11y):** 
  - Implemented `.skip-link` for keyboard navigation.
  - Fully accessible mobile menu with proper `aria-expanded` and `aria-controls` attributes.
  - Includes `@media (prefers-reduced-motion: reduce)` for users who prefer minimal animations.
- **Modern Layouts:** Built entirely with modern CSS Grid and Flexbox for a robust, pixel-perfect pricing table and responsive sections.
- **Glassmorphism Header:** A sticky navigation bar with a backdrop-blur effect that elegantly overlaps the hero section.

## 🛠️ Built With

- **HTML5** (Semantic & Highly Accessible Markup)
- **CSS3** (Custom Properties/Variables, CSS Grid, Flexbox, Advanced Transitions/Shadows)
- **Vanilla JavaScript** (ES6+ for interactive mobile menu state management)
- **Google Fonts** (Oswald for impactful display, Roboto for readability)
